# 设备验证清单（每个里程碑发版前执行一轮）

CI 只证明「构建得出、测试过」；本清单证明「真机好用」。发版前在下面每一行打勾并记录日期与设备，
结果追加到该版本 CHANGELOG 节尾（如「已过设备清单 2026-11-05，Pixel 5 / API 35」）。任何一项失败即阻塞发版。

## 环境

- 至少一台 arm64 真机（主力机优先），一台 Android TV（模拟器可接受）
- 网络环境：可直连的 Wi-Fi、一个可用订阅/节点、移动数据（可选）

## 安装与升级

- [ ] 新装：首次启动直达 Flutter 界面，无旧 Fragment 残影；VPN 授权弹窗正常
- [ ] 覆盖升级：从上一个已发布版本直接安装，数据（订阅/配置/设置/收藏）完整保留
- [ ] 跨大版本升级路径演练（仅里程碑大版本时）：备份 → 卸装 → 新装 → 恢复

## 核心

- [ ] 连接/断开/切换节点各三次，无崩溃；通知栏按钮切换生效
- [ ] TUN 模式下第三方应用真实走代理（浏览器打开 IP 查询）
- [ ] 分应用代理：排除/包含名单生效
- [ ] 切换 rule/global/direct 三模式各自生效
- [ ] 断网重连：飞行模式开关后自动恢复或一键重连成功
- [ ] FFI 驱动（3.3.0 起默认）：连接后通知栏速率与累计流量不再为 0，小组件同步
- [ ] FFI 驱动：仅在某 SSID 下生效的路由/DNS 规则，切换 Wi-Fi 后即时生效（无「Wi-Fi 规则不可用」通知）
- [ ] FFI 驱动：运行中删除被链式/分组引用的节点会被拦截；修改运行中分组的出站或路由后自动重载生效
- [ ] FFI 驱动：强杀进程后由系统重启服务（或「始终开启 VPN」）再打开界面，自动接管重连，无两个内核抢同一 TUN
- [ ] FFI 驱动：连接中关闭并重建 Flutter 界面后自动接管仍在运行的内核；从通知/磁贴停止后不残留 TUN，也不创建第二个内核

## 状态卡与探针

- [ ] 出口 IP/国家/组织显示正确；国旗与点击切码正常；长按刷新生效
- [ ] IP 质量区块在缓存未命中（新 IP）时能取到质量数据（v3.0.11 探针修复回归点）
- [ ] 探针进行中切走/取消，无崩溃、无残留错误提示
- [ ] 域名解析（设置 → 诊断）：未连接时提示「请先连接」；连接后解析 `example.com` 得到与出口一致的地址，无结果时显示原因而不是空白
- [ ] 域名解析输入 40 个域名（超过上限 32）不卡界面，返回后列表与输入顺序一致
- [ ] 代理页：进入后节点列表出现（不闪空、不残留空分组），返回后再次进入仍然完整；仪表盘的「超时」计数与代理页里超时的节点数一致
- [ ] 路由规则编辑：出站选择器能列出全部节点名，选中后保存生效（节点行已改为按需下发，这条是回归点）
- [ ] 外发 IP 详情：手动查询可返回地理/组织/风险结果；单源失败时仍显示其余源，全部失败时给出可重试错误

## 订阅与节点

- [ ] 导入订阅（URL/剪贴板/二维码）各一次成功
- [ ] 手动更新订阅 + 到期自动更新（观察一次即可）产生变更报告
- [ ] 节点 typed 表单新建/编辑/删除（至少覆盖 Shadowsocks、VLESS、Hysteria2 三协议）
- [ ] 批量测速面板：进度、直方图、连最快
- [ ] 路由规则导入：导入 sing-box 规则片段与 DNS `dns.rules` 片段后保存成功、规则可编辑且命中行为正确；列表字段可逐行增删改

## 数据层直读（#19，3.3.1-pre.11 起）

> 路由页数据可来自 SQLite 直读或 channel 回退，UI 不可区分是设计使然；以下关注的是「直读路径是否健康」。
> 所有 Preview/Stable 均使用正式包名 `com.throneflclash`，Preview 可直接覆盖正式版安装。
> release/preview 均不可 `run-as`；直读健康优先通过覆盖升级和路由页行为验证，只有在可 root 的测试设备上才拉库检查。

- [ ] 覆盖升级：`adb install -r Flrone-3.3.1-pre.11-*.apk` 成功；若失败，记录完整 `Failure [INSTALL_FAILED_…]` 码
      （静态实测三版包名/签名一致、versionCode 单调，失败即设备侧原因）
- [ ] 老库迁移：曾装过 schema < 19 版本的设备升级后首开路由页，字段不串位、不缺行（列名漂移的运行时表现；
      CI 的 schema_audit 只能拦住源码侧漂移）
- [ ] WAL 并发读：触发订阅更新（写库）的同时反复进出路由页，无可感知卡顿/ANR；
      辅证：`adb shell dumpsys gfxinfo com.throneflclash` 的 jank 统计
- [ ] 直读路径确认：在可 root 的测试设备读取 `/data/data/com.throneflclash/databases/sager_net.db`，
      `PRAGMA user_version` 应为 19；若不可 root，记录路由页正常且无回退日志作为辅证
      （回退路径不读该文件）
